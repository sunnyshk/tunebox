# Tunebox

A music and video player for Android.

## Install

1. Download the latest `Tunebox-<version>.apk` from [Releases](https://github.com/sunnyshk/tunebox/releases/latest).
2. Open it on your phone and allow installing from your browser or file manager when asked.

## Updates

Tunebox checks this page for new versions by itself and offers to install them.
You can also check any time from the ⋮ menu > Check for updates.
